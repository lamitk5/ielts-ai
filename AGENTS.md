# IELTS AI Tutor

## Stack

React + Vite + Tailwind CSS + Framer Motion + React Router + Recharts.

## Direction

- Backend: Java Spring Boot.
- Database: PostgreSQL + pgvector.
- Design: Academic Luxury.

## Core rules

- Use approved colors only unless the spec explicitly changes.
- Use Playfair Display for headings and Inter for body/UI.
- Reuse shared components; do not duplicate Button, GlassCard, or animation patterns.
- Add dependencies only when the current task clearly needs them.
- Implement one task at a time; do not implement future phases early.
- Treat Reading, Listening, Writing, and Speaking as first-class areas.
- Label AI-produced IELTS scores as estimates later.
- Keep frontend code independent of vendor-specific AI payloads.
- Respect reduced motion and accessibility.
